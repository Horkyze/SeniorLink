# SeniorLink 0.1.13 — encrypted queued delivery

Approved phones can now exchange retained updates without being online at the
same time. An optional Cloudflare mailbox stores a separate encrypted copy for
each caregiver. Existing direct phone-to-phone synchronization continues to work.

## Set up queued delivery

1. Update both phones to 0.1.13, preserving app data and existing pairing.
2. In **Settings → Encrypted queued delivery**, copy each phone's public
   **Mailbox phone ID** and give it to the mailbox operator for admission.
   Phone private keys stay on the phones.
3. Enter the same mailbox setup code on both phones and enable each other.
4. Keep both apps online with sharing enabled on the sharing phone until initial
   setup completes. Afterwards, uploaded updates can arrive while that phone is
   offline.

The private Worker has been deployed, but real phone access initially remains
closed. Its [public setup code](https://github.com/Horkyze/SeniorLink/blob/v0.1.13/mailbox/setup-code.txt)
is not an access credential. See the
[operator guide](https://github.com/Horkyze/SeniorLink/blob/v0.1.13/mailbox/README.md)
for deployment, phone admission and configuration.

## Delivery and control

- Requests authenticate with existing iroh identities. Message contents use HPKE
  encryption for the caregiver; Cloudflare does not have the decryption key.
- A durable phone outbox retries uploads. Settings distinguishes **pending upload**,
  **stored in mailbox**, and **caregiver-confirmed receipt**. Received events are
  saved before acknowledgment; retries and direct sync do not create duplicates.
- Retrieval uses a **24-hour authorization lease**, renewed while sharing can run.
  Messages expire seven days after their original local storage time. Existing
  per-phone history limits and Android background restrictions still apply.
- Pause, feature withdrawal and peer revocation persist pending deletion. If the
  phone is offline, the server cannot learn that decision immediately: retrieval
  may continue until the existing lease expires. Already received copies cannot
  be recalled.
- This adds no collection, push notifications, remote activation or guarantee of
  immediate delivery. Caregiver mode still does not collect caregiver data.
  Stored ciphertext does not have forward secrecy with the static recipient key.

## Download and update

Download **SeniorLink-0.1.13-debug.apk** from the release assets. Install it as an
update without uninstalling to keep identity, pairing, settings and history.
Its signing certificate matches published 0.1.12. The local database migrates
from schema 2 to 3 without resetting existing data.

Direct sync remains protocol 3 and works with versions 0.1.7–0.1.13. Both phones
need 0.1.13 only for mailbox setup and delivery, which use the separate
`family.seniorlink/mailbox-control/1` setup protocol. Versions 0.1.6 and older must
be updated for direct sync. This remains a debug-signed family pilot prerelease
for Android 8.0 or newer, including ARM64, ARMv7 and x86-64.
