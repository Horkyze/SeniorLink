# SeniorLink 0.1.4 — location map and history

Open **Location**, or **Updates → View location map**, to see the latest known
position and previous locations on an interactive map. Select a phone, tap a
marker or a history entry, and inspect its recorded time and accuracy.

## Download and update

Download **SeniorLink-0.1.4-debug.apk** from the release assets and install it on
both phones. Android 8.0 or later is required; ARM64, ARMv7 and x86-64 are included.
Version 0.1.3 offers this update when you open the app. Older versions can use the
APK download directly.

This APK uses the **same signing certificate as the published 0.1.0–0.1.3 APKs**.
Install it as an update, without uninstalling, to retain identities, paired phones
and history. Existing history is migrated in place for the new location index.
This remains a debug-signed family pilot prerelease.

## What changed

- An embedded, zoomable map shows the latest known location in teal and previous
  fixes in amber. A ring highlights the selected fix.
- **Latest location** centers the newest fix; **Show history** fits the saved
  locations on the map. You can also open the selected point in a maps app.
- Each sharing phone has its own location history, ordered by fix time. Up to
  1,000 retained fixes are available independently of the 100-event Updates feed,
  so SMS and unlock activity cannot crowd locations out.
- Missing-location screens explain how to enable sharing or receive the first
  fix. Offline screens keep coordinates and history accessible.
- Navigation and map controls wrap for large text. Caregiver maps need no
  location permission, Google Play Services or API key.

Locations are recorded approximately every 15 minutes when Android provides a
fix; the map shows saved readings, not live tracking. Enable **Settings → Share
location**, save, and start sharing on the sharing phone to collect locations.

Map tiles use OpenStreetMap. Its tile service receives the viewer's IP address
and requested map areas; names, event timestamps and history are rendered on the
phone. Uncached map areas require internet. History retains the existing seven-day
storage policy.

## Verification

- 23 core and 23 Android unit tests pass, including database migration, retention,
  source separation and location history surviving a busy Updates feed.
- Five location UI tests pass on Android 17 / API 37.1 with 16 KB pages, covering
  history selection, multiple phones, missing data, removal, background/resume
  and offline operation. The selection workflow also passes at 2× font scale.
- Real map tiles and selected markers were visually inspected with synthetic data.
- APK build, lint, signature, all three native ABIs, 16 KB ELF/ZIP alignment and
  checksum-verified archive reconstruction pass.
- Signing compatibility is checked against the published 0.1.3 APK. Physical
  phone verification remains outstanding. See the
  [verification record](https://github.com/Horkyze/SeniorLink/blob/v0.1.4/docs/verification.md).

To verify the download, put the APK and `SHA256SUMS` in one directory and run:

```sh
# macOS
shasum -a 256 -c SHA256SUMS
# Linux
sha256sum -c SHA256SUMS
```
