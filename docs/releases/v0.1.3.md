# SeniorLink 0.1.3 — update prompts on startup

SeniorLink now checks for newer versions in the background when you open the app.
When a newer APK is available, choose **Download update** to open it in your
browser or **Later** to keep using the app.

## Download and update

Download **SeniorLink-0.1.3-debug.apk** from the release assets and install it on
both phones. Android 8.0 or later is required; ARM64, ARMv7 and x86-64 are included.

Install this version manually to enable prompts for future updates. Versions
0.1.0–0.1.2 do not include the startup update check.

This APK uses the **same signing certificate as the published 0.1.0–0.1.2 APKs**.
Install it as an update, without uninstalling, to retain identities, paired phones
and history. This remains a debug-signed family pilot prerelease.

## What changed

- Checks published GitHub releases, including the family pilot prereleases,
  without delaying app startup or sharing.
- Compares version numbers correctly and offers only newer releases with an APK.
- Opens the APK download only after you tap **Download update**. Installation is
  completed through Android after the download.
- **Later** dismisses the prompt until the next app launch. Rotating the phone or
  returning from the browser does not repeat the check.
- Offline, timeout and failed checks remain silent. If no browser can open the
  download, the prompt provides a copyable link.
- The prompt waits for active pairing dialogs and app messages to close.

## Verification

- 23 core and 20 Android unit tests pass, including version comparison, release
  selection, network failures, cancellation and activity recreation.
- The Android 15 ARM64 emulator passes the three update prompt tests and the
  existing sharing/check-in/pause workflow. Update prompt tests also pass at
  Android's 2× system font scale; rendered layouts were inspected.
- Debug APK build and lint pass. Native ABI and 16 KB alignment packaging checks
  and checksum-verified archive reconstruction pass.
- An in-place update from the published 0.1.2 APK preserves settings, encrypted
  identity and check-in history. A new check-in uses the same permanent identity.
  See the [verification record](https://github.com/Horkyze/SeniorLink/blob/v0.1.3/docs/verification.md).

To verify the download, put the APK and `SHA256SUMS` in one directory and run:

```sh
# macOS
shasum -a 256 -c SHA256SUMS
# Linux
sha256sum -c SHA256SUMS
```
