# SeniorLink 0.1.1 — in-app QR pairing

**Debug-signed family pilot prerelease.** Not an emergency-response or medical device.

## Download and update

Download `SeniorLink-0.1.1-debug.apk` from the release assets, not the source-code
archives. Install the same APK on the sharing phone and each caregiver's phone.
Requires Android 8.0 or later; ARM64, ARMv7 and x86-64 are included.

This APK uses the **same signing certificate as the published 0.1.0 APK**. Install
it as an update without uninstalling. An emulator upgrade check preserved the role,
identity, paired phones and retained history. Builds from another machine or CI
may use a different signing key; do not uninstall to work around a signature
mismatch without considering the loss of pairing and history.

To verify a download, place the APK and `SHA256SUMS` in the same directory and run:

```sh
# macOS
shasum -a 256 -c SHA256SUMS
# Linux
sha256sum -c SHA256SUMS
```

## What's new

- **In-app QR scanner:** bundled offline decoding, no external camera app or
  Google Play Services required.
- **Show my QR code:** a dedicated view with copy/share fallback.
- Scans fill the pairing form but never silently approve access. Invalid/self-codes
  are rejected, and changing a scanned or pasted code resets approval.
- Camera permission is requested only when scanning. Cancel and backgrounding close
  the camera; frames are not saved or uploaded.
- Pairing drafts survive activity recreation. Loading/setup/content transitions no
  longer use early returns that triggered a Compose slot-table failure during testing.

## Pair phones

1. On one phone, open **Phones → Show my QR code**.
2. On the other, tap **Phones → Scan other phone's QR** and allow Camera.
3. Enter a phone name and explicitly confirm Add/Approve.
4. Swap directions and repeat. Complete both directions for each caregiver.

After both phones are configured, tap **Start sharing** on the sharing phone.
See the [installation and pairing guide](https://github.com/Horkyze/SeniorLink/blob/v0.1.1/README.md#install-and-pair).

## Verification and limitations

- 7 core tests and 9 Android unit tests pass.
- All 6 instrumented tests pass on an Android 15 ARM64 emulator, plus a separate
  caregiver-mode pairing run.
- APK native packaging/alignment, signature, and archive reconstruction are verified.
- UI tests inject synthetic scan results; QR decoding and actual camera lifecycle
  are tested separately. Optical phone-to-phone scanning and manufacturer-specific
  camera behavior still need physical-phone validation.

Existing pilot reliability limitations still apply: both phones must be reachable
while the caregiver app is open, Android can interrupt sharing, and there are no
closed-app push alerts or guaranteed delivery times.

See the [verification record](https://github.com/Horkyze/SeniorLink/blob/v0.1.1/docs/verification.md)
and [real-phone acceptance checklist](https://github.com/Horkyze/SeniorLink/blob/v0.1.1/docs/acceptance.md).
