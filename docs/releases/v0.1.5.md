# SeniorLink 0.1.5 — version and update checks in Settings

Open **Settings → App updates** to see the installed version and tap **Check for
updates** whenever you want to look for a newer release.

## What changed

- Shows **Current version: 0.1.5** at the top of Settings in both sharing and
  caregiver mode.
- Displays checking progress and prevents repeated taps from starting duplicate
  requests, including while the startup check is running.
- Reports **You're up to date** only after a successful check. Offline, server
  and invalid-response failures show a message and allow another attempt.
- Offers a newer APK through the existing **Download update / Later** prompt.
  Downloads open only after you accept. You can check again after choosing Later
  without restarting the app.
- Keeps automatic startup checks quiet when they fail. Manual checks are also
  available while sharing is active.

## Download and update

Download **SeniorLink-0.1.5-debug.apk** from the assets and install it as an update.
The APK uses the same signing certificate as the published 0.1.0–0.1.4 APKs.
**Do not uninstall first** if you want to keep identities, pairing and history.
Versions 0.1.3–0.1.4 check for this update when opened; older versions can use the
APK download directly.

This is a debug-signed family pilot prerelease for Android 8.0 or later, including
ARM64, ARMv7 and x86-64. Both roles use the same APK.

## Verification

- 23 core and 28 Android unit tests pass, including result classification, retries,
  duplicate-request prevention, retained state and cancellation.
- Settings and download-prompt checks run on the Android 17 emulator, including
  both roles, failure/retry, explicit download approval and large text.
- Build, lint, signature compatibility, native ABI/16 KB alignment and archive
  reconstruction are checked. See the
  [verification record](https://github.com/Horkyze/SeniorLink/blob/v0.1.5/docs/verification.md).

Download `SHA256SUMS` alongside the APK to verify it:

```sh
# macOS
shasum -a 256 -c SHA256SUMS
# Linux
sha256sum -c SHA256SUMS
```
