# SeniorLink 0.1.11 — faster sync and settings without pausing

Caregivers now fetch retained history over one encrypted connection instead of
reconnecting every 20 records. The wait between pages is removed. In a synthetic
1,000-record emulator comparison, catch-up took 1.75 seconds instead of 6.26
seconds; physical-phone timing depends on the network and devices.

## Sharing settings

- **Save changes while sharing is on.** You no longer need to pause first.
  Android asks for any newly required permission before applying an active
  configuration. Denial keeps the previous settings running.
- New sharing setups select **phone battery, unlock activity and location** by
  default, with an explanation before pairing. Review the choices in Settings.
  Existing saved choices are preserved during an update; disabled features stay
  disabled. SMS, wearables and Telegram still require separate setup.
- Unsaved feature choices survive tab navigation and screen rotation.
- Saving while paused keeps sharing paused. A late permission response cannot
  restart it. Background location still follows Android's permission rules.

## Battery readings

Missing-battery cards now explain what to check. Enabling phone battery and saving
while sharing starts sampling promptly. To enable it on an existing installation,
open **Settings → Share phone battery**, turn it on and tap **Save settings**.

The first supported wearable-battery reading is saved promptly. Reconnecting no
longer hides a saved battery reading when heart rate arrives first; saved values
keep their original timestamps. Watches that do not provide a supported battery
measurement still show **Unknown**.

## Download and update

Download **SeniorLink-0.1.11-debug.apk** from this release's assets. **Install as an
update without uninstalling** to preserve identity, pairing, settings and history.
The APK uses the same signing certificate as published 0.1.10.

Update both phones to 0.1.11 to use connection reuse. Protocol 3 is unchanged;
0.1.7–0.1.11 can still sync together, with page-by-page reconnection for older
sharing phones. Phones running 0.1.6 or older must be updated.

This remains a debug-signed family pilot prerelease for Android 8.0 or newer,
including ARM64, ARMv7 and x86-64. No new physical wearable compatibility or
medical-reliability claims are made.
