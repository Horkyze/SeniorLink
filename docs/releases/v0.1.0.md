# SeniorLink 0.1.0 — family pilot

Initial **debug-signed prerelease** for voluntary family safety sharing.
This is not an emergency-response or medical device.

## Install

Download `SeniorLink-0.1.0-debug.apk` from the release assets, not the source-code
archives. Install the same APK on the sharing phone and each caregiver's phone.
Requires Android 8.0 or later; ARM64, ARMv7 and x86-64 are included.

To verify a download, place the APK and `SHA256SUMS` in the same directory and run:

```sh
# macOS
shasum -a 256 -c SHA256SUMS
# Linux
sha256sum -c SHA256SUMS
```

Follow the [installation and pairing guide](https://github.com/Horkyze/SeniorLink/blob/v0.1.0/README.md#install-and-pair).
Each caregiver must be explicitly approved on the sharing phone.

## Included

- Encrypted iroh peer connections and independent history catch-up per caregiver.
- Opt-in location, best-effort unlock activity, selected-sender SMS, and manual
  “I'm okay” check-ins. SMS bodies are off by default.
- Optional Telegram forwarding configured locally on the sharing phone.
- Visible foreground notification and an explicit Pause action.

## Verification

The existing pilot verification records 6 core tests, 7 Android SQLite unit tests,
and 4 instrumented tests on an Android 15 ARM64 emulator, plus manual synthetic
SMS, location and unlock workflows. APK signature, native ABI packaging, alignment,
and archive reconstruction were checked.

See the [verification record](https://github.com/Horkyze/SeniorLink/blob/v0.1.0/docs/verification.md)
and [real-phone acceptance checklist](https://github.com/Horkyze/SeniorLink/blob/v0.1.0/docs/acceptance.md).

## Limitations

- The sharing phone must be running and reachable when a caregiver opens the app.
  There are no closed-app push alerts or guaranteed delivery times.
- Android battery restrictions, reboot or force-stop can interrupt sharing.
  Physical-phone and overnight reliability have not yet been established.
- No live Telegram integration test was performed; configure credentials in the
  app and use its test button. Telegram bot messages are not end-to-end encrypted.
- This APK uses a debug signing key. Updates must retain that key. Builds from
  another machine or CI may use a different key and require uninstalling, which
  deletes stored history and pairing. Do not uninstall merely to update without
  considering this data loss.
